Google Gemini API കീ ക്രമീകരണം

Google Gemini വോയ്സ് എൻജിൻ ഉപയോഗിക്കാൻ മാത്രം API കീ നൽകുക.

സൗജന്യ കീ എങ്ങനെ ലഭിക്കും?
  1. aistudio.google.com/app/apikey സന്ദർശിക്കുക.
