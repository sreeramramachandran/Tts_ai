# മലയാളം AI വോയ്സ് & 2D വീഡിയോ (Malayalam AI Voice & 2D Story Video)

A 100% free, mobile-first web software powered by **Google Gemini 3.8 Flash TTS** and **Pollinations AI Flux**. It creates:
1. **Expressive Malayalam Text-to-Speech** with real human laughter (`[laugh]`), chuckles (`[giggles]`), whispers (`[whispers]`), and authentic Kerala slang.
2. **2D Animated Story Videos** with visual scenes matching whatever objects/characters you mention (forest, river, boat, dragon, etc.), smooth Ken Burns camera pan/zoom motion, floating atmospheric particles, Malayalam karaoke subtitles, and 1-click **.MP4 Video Download**!

---

## 🌟 Two Modes in One App

- **Mode 1: 🔊 ഓഡിയോ മാത്രം (Audio Only)**:
  - Generates spoken audio in 2 seconds.
  - Native playback with waveform and speed controls (0.85x, 1x, 1.15x, 1.25x).
  - Download `.wav` audio file.

- **Mode 2: 🎬 2D സ്റ്റോറി വീഡിയോ (2D Video + Audio)**:
  - Gemini analyzes your story and breaks it into visual scene descriptions.
  - Generates 2D anime/storybook illustrations for each scene (depicting the river, boat, forest, dragon, etc.).
  - 16:9 widescreen canvas with smooth cinematic camera zoom/pan.
  - Floating atmospheric particles (drifting leaves, fog, water glimmers).
  - Synchronized Malayalam subtitles.
  - **📥 Download Video (.MP4 / .WebM)** + Download Audio (.WAV).

## 🚀 How to Run Locally

### 1. Start the Server
In your terminal / PowerShell in `d:\voice`:
```bash
node server.js
```

### 2. Open in Browser
- **On PC:** [http://localhost:3000](http://localhost:3000)
- **On Phone (Same Wi-Fi):** `http://192.168.29.36:3000`

## 🔑 Free Setup
1. Get your free API key from [Google AI Studio](https://aistudio.google.com/app/apikey).
2. Click the **⚙️ API Key** button in the app and save it.
3. Everything else (including 2D image generation) runs 100% free with no extra keys required!
